# Logophile

你喜欢语言吗？

你喜欢收集那些第二常见的单词吗？

又或者，你在为没有快捷的方式来查询、收藏那些美丽的词语而烦恼？！

别走开，因为这个APP将为你提供一个优雅的解决方案！



## 在这个APP里，你可以

- 随时随地输入一个单词，APP将自动联网获取释义、音标以及音频，一键添加到你的词库！
- 浏览你的词库！按字母顺序、添加时间排序，或是选择时间范围！（哦，伟大的词库！您的长度今天也令我们骄傲）
- Can't just stash！不只是想当个收藏家？去"记忆"界面，用你的手指抚摸每一个词语（Like they would love you to），去回应它们对你的感受



## 技术

Kotlin + Jetpack Compose · Room 数据库 · Retrofit 网络请求 · DataStore 偏好存储



## 构建

Android Studio 打开项目，Gradle 同步后直接运行即可。最低支持 Android 10（API 29）。
